# Entrega de documentacion - Control MVP

Este directorio agrupa la documentacion principal de entrega del proyecto Control MVP del Laboratorio de Idiomas EAFIT.

## Documento principal recomendado

- Documento_integrado_entrega_Control_MVP.md

Este archivo consolida en un solo texto:

- descripcion general del proyecto
- alcance del MVP
- actores y roles
- entidades de informacion
- arquitectura funcional
- modulos principales
- flujos detallados del sistema
- estados y reglas de negocio
- ficha tecnica consolidada
- validacion tecnica y funcional
- explicacion del prototipo entregable
- observaciones finales de entrega

## Prototipo funcional incluido

- Prototipo/Control_MVP_final_20260505_canceladas.msapp

En este proyecto, el prototipo correcto es el archivo .msapp, ya que corresponde al artefacto funcional de Power Apps Canvas listo para ser importado o revisado en Power Apps Studio.

## Entregable pendiente por adjuntar por el equipo

- Base de datos de inventario en formato .xlsx

## Recomendacion de envio

La forma mas ordenada de entregar el proyecto es enviar este directorio junto con el archivo .xlsx pendiente, de manera que el docente reciba la documentacion consolidada y el prototipo funcional en un solo paquete.
